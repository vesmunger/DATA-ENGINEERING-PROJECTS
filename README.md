## Projects Overview

| Project Name      | Description                                           | Tech Stack                               | Purpose / Skills Demonstrated |
|------------------|-------------------------------------------------------|-----------------------------------------|-------------------------------|
| **Faker**         | Generate synthetic datasets for testing & dev       | Python, Pandas                           | Test ETL pipelines, simulate real-world data |
| **Gas Prices**    | Scrapes US gas prices and stores in MongoDB         | Python, Requests, Pandas, MongoDB        | API integration, ETL processing, automated ingestion |
| **OpenWeather**   | Streams real-time weather data                       | Python, Requests, Pandas, MongoDB        | Real-time data ingestion and cleaning |
| **Weather_Airflow** | Full Airflow pipeline for weather data            | Python, Airflow, Pandas, MongoDB         | Orchestrated ETL pipelines, XCom usage |
| **Weather_Kafka** | Streams weather data into Kafka topics              | Python, Kafka, Pandas                     | Real-time streaming, topic management |
| **Crypto**        | Fetches cryptocurrency market data from CoinGecko  | Python, Requests, Pandas, Airflow, MongoDB | API integration, ETL with Airflow, database storage |
