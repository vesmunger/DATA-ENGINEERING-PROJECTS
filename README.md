This repository contains multiple data engineering projects demonstrating ETL, web scraping, data streaming, and workflow automation skills:

1. **Faker Data Generator** – Generate synthetic datasets for testing ETL pipelines.
2. **Gas Price Scraper** – Scrape gas prices from multiple sources, automated using Airflow DAGs.
3. **Weather Data Stream** – Stream real-time weather data from OpenWeather API with Airflow scheduling.
4. **ML-ETL Package** – Python package for automating ETL workflows, published on [PyPI](https://pypi.org/project/ml-etl-package/).
